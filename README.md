## Homelab

An old laptop with Debian 13. Every service runs in Docker, nothing is open to the internet, and I reach it all through Tailscale.

- **Network:** Pi-hole for DNS and ad blocking, Caddy for `.lab` names, Tailscale VPN
- **Services:** Vaultwarden, Joplin Server, Navidrome, Syncthing, Homarr
- **Monitoring:** Uptime Kuma, Beszel, ntfy alerts, weekly Restic backups
- **Local AI:** Ollama and Open WebUI, running small models on the CPU
